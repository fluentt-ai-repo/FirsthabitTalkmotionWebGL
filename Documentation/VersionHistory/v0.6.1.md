**릴리스 날짜**: 2026-04-08

## 주요 변경사항

### 1. 아바타 이름 전면 변경
10종 아바타 프리팹의 ID를 외부 제공용 이름으로 변경했습니다.

| new07 | owen |

- `AvatarCatalog.asset` 업데이트
- Flutter 테스트 앱 fallback 목록 업데이트

### 2. One-Shot Motion 그룹 `Listening2` 추가
Flutter 테스트 앱에 Listening2 버튼을 추가하고, 버튼 레이아웃을 `Row` → `Wrap`으로 변경하여 그룹 추가 시 자동 줄바꿈되도록 했습니다.

### 3. 콘솔 로그 대폭 정리
외부 협력사 제공 시 콘솔 품질을 개선하기 위해 중복 로그를 전면 제거했습니다.

- **jslib**: 모든 콜백 함수의 `console.log` 제거 (`console.error`만 유지)
- **index.html**: `sendToUnity` 실행 로그, 큐잉 로그 제거
- C# `Debug.Log`만 단일 출력

### 4. sendToUnity 메시지 큐
Unity 인스턴스가 준비되기 전에 호출된 `sendToUnity` 메시지를 큐에 저장하고, 인스턴스 연결 후 자동으로 전송하도록 개선했습니다.

- `Unity instance not ready yet` 에러 해결

### 5. WebGL 빌드 최적화
Wasm2023 + Code Stripping High 적용으로 빌드 용량을 절감했습니다.

| 파일 | 이전 | 이후 | 절감 |
|------|------|------|------|
| `.wasm` | 54 MB | 42 MB | -22% |
| `.data` | 37 MB | 34 MB | -8% |
| **합계** | **91 MB** | **76 MB** | **-16%** |

### 6. Chrome AudioContext 경고 대응
Unity iframe 내 첫 사용자 클릭 시 AudioContext를 resume하는 핸들러를 추가했습니다.

### 7. SDK 경고/버그 요구사항 문서 작성
SDK 측에 전달할 경고 수정 요청서를 작성했습니다 (`docs/SDK_WARNING_FIX_REQUEST.md`).

- VirtualTargets 런타임 자동 생성 요청
- PlayPrepared 후 `isTalkMotionActive` 미복구 버그
- `tagged_motion is NULL` 경고 레벨 조정
- SDK 초기화 로그 과다 출력 정리 요청
