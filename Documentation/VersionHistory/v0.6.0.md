# v0.6.0 - One-Shot Motion 브릿지 연동

**릴리스 날짜**: 2026-04-07

## 주요 변경사항

### 1. One-Shot Motion 브릿지 연동
Flutter 테스트 앱에서 Listening/Thinking 모션을 트리거할 수 있는 전체 파이프라인을 구현했습니다.

#### C# Bridge (`FirsthabitWebGLBridge.cs`)
- `PlayOneShotMotion(json)` — 단일 모션(`motionId`) 또는 그룹 루프(`groupId`) 지원
- `StopOneShotMotion()` — 현재 재생 중인 원샷 모션 중지
- `GetOneShotMotionList()` — 등록된 모션/그룹 ID 목록 조회
- 콜백 등록/해제: `onOneShotMotionStarted`, `onOneShotMotionEnded`

#### jslib 콜백
- `FH_OnOneShotMotionStarted`, `FH_OnOneShotMotionEnded`, `FH_OnOneShotMotionList`

#### Dart Bridge (`unity_bridge.dart`)
- Stream controllers + `playOneShotMotionGroup()`, `playOneShotMotion()`, `stopOneShotMotion()`, `getOneShotMotionList()`

#### Flutter UI (`main.dart`)
- "One-Shot Motion" 섹션에 Listening / Thinking / Stop 버튼 추가

### 2. 아바타 프리팹 One-Shot Motion Group 설정
10종 아바타 프리팹에 Listening, Thinking 모션 그룹을 설정했습니다.

### 3. 미사용 애니메이션 파일 대량 정리
Emotion, ProcessedAnimations, ProcessedAnimations2, TriggerMotion, added motion 폴더의 미사용 파일 약 400개를 삭제하여 저장소 용량을 절감했습니다.
