# v0.5.2 - AvatarCatalog 리팩토링, SDK 브랜치 전환

**릴리스 날짜**: 2026-04-06

## 주요 변경사항

### 1. AvatarCatalog ScriptableObject 분리
아바타 목록을 Bridge 컴포넌트에서 분리하여 `AvatarCatalog` ScriptableObject로 관리하도록 리팩토링했습니다.

- Inspector에서 아바타 프리팹 목록을 독립적으로 관리 가능
- 아바타 추가/제거 시 Bridge 코드 수정 불필요

### 2. SDK 브랜치 전환
avatar-controller 및 talkmotion 패키지의 SDK 브랜치를 전환했습니다.

### 3. 에디터 도구 추가
애니메이션 커브 정리 등 개발 편의를 위한 에디터 도구를 추가했습니다.
