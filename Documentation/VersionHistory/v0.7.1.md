# v0.7.1 - 인수인계 baseline

**릴리스 날짜**: 2026-04-27

본 릴리스는 v0.7.0에 이어, 인수인계 baseline을 안정화하기 위한 정합화 변경을 모은 패치 릴리스입니다. 런타임 동작 변경은 없습니다.

## 주요 변경사항

### 1. SDK 종속성 SHA 핀

`unity/Packages/manifest.json`의 자체 SDK 두 개에 `#SHA` 표기를 추가하여 빌드 재현성을 보장합니다. SDK 저장소에 새 커밋이 push되더라도 본 프로젝트는 고정된 커밋만 사용합니다.

- `com.fluentt.avatar-controller-sample-floating-head` → `3e70755b`
- `com.fluentt.talkmotion` → `537bcb18`

`unity/Packages/packages-lock.json`의 `version` 필드도 동일 SHA로 동기화. `hash` 필드는 변경 없음 (코드 동일, 핀만 명시화).

### 2. TalkmotionServerSettings FaceHead.asset — serverURL 공란화

`unity/Assets/TalkmotionServerSettings FaceHead.asset`의 `serverURL` 필드를 공란으로 비웠습니다. 본 필드는 talkmotion SDK가 제공하는 외부 백엔드 통신 URL 자리이며, 본 인수인계 baseline에서는 인수자가 자체 환경에 맞는 백엔드 URL을 직접 입력하여 활성화하도록 비워두는 것이 일관됩니다.

- 변경: `serverURL: https://api.talkmotion.ai` → `serverURL:`
- 영향 없음: 10개 캐릭터 프리팹의 `customServerSettings` 참조는 그대로 유지
- 인수자 처리: 자체 백엔드 구성 시 본 필드에 자체 URL 입력

### 3. 해결된 SDK 이슈 문서 정리

다음 SDK 이슈 문서가 모두 해결 완료되어 `docs/` 폴더에서 제거 (폴더 자체가 비워지며 정리됨).

- `docs/SDK_EYE_OVERRIDE_BUG_REPORT.md` (해결)
- `docs/SDK_FEATURE_REQUEST_BaseExpression.md` (해결)
- `docs/SDK_WARNING_FIX_REQUEST.md` (해결)

본 이슈들은 인수 시점에 모두 해결된 상태이며, 알려진 이슈 baseline에 미해결 항목으로 등재되지 않습니다.

### 4. CLAUDE.md / FIREBASE_DEPLOY.md 안내 갱신

- `CLAUDE.md` "배포" 섹션: 시연용 Firebase Hosting URL이 셧다운되었음을 명시. 인수자는 자체 Firebase 프로젝트로 신규 배포 필요.
- `FIREBASE_DEPLOY.md`: 최상단에 안내 박스 추가. 기존 명령·절차는 인수자 자체 환경에서의 참고용으로 유지.

### 5. CLAUDE.md "남은 과제 목록" 정리

본 릴리스 시점 기준 처리 완료 항목을 정리하고, 인수자 후속 권장 항목 1건만 남겼습니다.

**처리 완료**: Play 버튼 렉, Stop 부드럽게 종료, FPS 최적화, Queue 모드, Idle 다양화, 모션 트리거, 투명 배경, 아바타 런타임 교체, 자막 텍스트 전달, 콜백 검증, WebGL 호환성/용량 체크, 렌더링 일치

**유일 잔존 (인수자 후속 권장)**: Addressable 에셋 전환 — 인수자 측 자체 운영 환경에서 진행 시 로딩/용량 최적화 효과
