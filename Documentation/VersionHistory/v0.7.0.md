# v0.7.0 - MagicaCloth2 → Dynamic Bone 전환, 에러 처리 강화

**릴리스 날짜**: 2026-04-08

## 주요 변경사항

### 1. MagicaCloth2 → Dynamic Bone 전환 (Breaking)
MagicaCloth2는 WebGL 플랫폼을 지원하지 않아(멀티스레딩 필수) 클로스 시뮬레이션이 동작하지 않았습니다. Dynamic Bone으로 전면 교체하여 WebGL에서도 머리카락/옷 물리가 정상 동작합니다.

- **Dynamic Bone 1.3.4** 도입 (WebGL 멀티스레드 자동 비활성화 지원)
- 아바타 9종 프리팹에 Dynamic Bone 컴포넌트 적용 (kai 제외 — 원래 클로스 미적용)
- MagicaCloth2 패키지 전체 삭제

#### Dynamic Bone 파라미터
| 파라미터 | 값 | 설명 |
|----------|-----|------|
| Damping | 0.2 | 자연스러운 감쇠 |
| Elasticity | 0.1 | 원래 자세로 복귀 |
| Stiffness | 0.8 | 형태 유지 (뿌리 고정, 끝만 흔들림) |
| Inert | 0.0 | 몸 움직임 즉시 추종 |
| Gravity | (0, -0.002, 0) | 미세한 중력 |

### 2. 아바타 미소환 시 에러 처리 강화
아바타를 소환하지 않은 상태에서 기능을 호출할 때 명확한 에러 메시지를 반환하도록 개선했습니다.

- 모든 아바타 의존 메서드에 `RequireAvatar()` 가드 추가
- 기존: `NullReferenceException` → 혼란스러운 내부 에러 (예: "Delegate to an instance method cannot have null 'this'")
- 변경: `"No avatar loaded. Call ChangeAvatar first."` 통일된 에러 메시지
- 대상: PrepareAudio, Play, Stop, SetVolume, GetCacheInfo, ClearAllCache, Chat, Speak, PlayOneShotMotion, StopOneShotMotion, GetOneShotMotionList

### 3. WebGL 빌드 업데이트
Dynamic Bone 적용 상태로 WebGL 재빌드.
