# v0.5.0 - Chat/Speak API 브릿지 노출 및 다중 문장 버그 수정

**릴리스 날짜**: 2026-04-03

## 주요 변경사항

### 1. Chat/Speak API 브릿지 노출
외부에서 Chat(LLM→TTS→Motion) 및 Speak(TTS→Motion) 기능을 사용할 수 있도록 브릿지에 노출했습니다.

- `Chat(json)` — LLM 대화 → TTS → 모션 재생. `prepareOnly` 옵션으로 캐싱만 가능
- `Speak(json)` — 텍스트 → TTS → 모션 재생. `subtitleText` 별도 지정 가능
- Flutter 테스트 앱에 Chat/Speak 입력 UI 추가

### 2. 다중 문장 재생 버그 수정
`StartChat`/`StartSpeak` 사용 시 첫 문장만 재생되고 후속 문장이 무시되는 버그를 수정했습니다.

- `onSentenceStarted`에서 `isFirstSentence` 체크로 `PlaybackStarted` 콜백 발생 시점 조정
- `onSentenceEnded`에서 `isLastSentence` 체크로 `PlaybackCompleted`를 마지막 문장 후에만 발생

### 3. Unity 프로젝트 버전 동기화 규칙 추가
main merge + 버전 태그 생성 시 Unity `ProjectSettings/ProjectSettings.asset`의 `bundleVersion`도 동일하게 업데이트하는 규칙을 CLAUDE.md에 추가했습니다.
